# UI Redesign (Flagship Pass) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the warm-monochrome design system (new color tokens, a serif display font, pill buttons, soft-elevation cards, a formalized status-pill pattern) to AgentSim's flagship template — `Header` + `RunView` and everything `RunView` transitively composes — with zero interaction or layout changes.

**Architecture:** A new set of color/spacing/shape tokens lands once in `src/ui/styles.ts` (the file every component already imports its class-name constants from) plus one new font in `src/app/layout.tsx`. Every other file in the flagship's component tree currently hardcodes raw hex literals rather than importing the shared tokens, so those literals get swept to the new values directly, file by file, in one mechanical pass. A handful of call sites that render a solid-fill "Capped"/"Lure taken" badge get restructured into the new soft-pastel pill shape. `systemColor.ts`'s per-System hue rotation is touched only at its neutral fallback, not its 8-hue palette.

**Tech Stack:** Next.js 16 App Router, Tailwind v4 (arbitrary-value hex classes, no theme config), `next/font/google`, React 19, TypeScript strict.

**Spec:** `docs/superpowers/specs/2026-09-16-ui-redesign-design.md`

## Global Constraints

- Light-only. No dark-mode token pairs in this plan — every value below is a single, flat hex string.
- No interaction or layout change anywhere — react-flow's canvas behavior, the Launcher's form
  controls, the Timeline/Flow toggle, replay, drawer open/close: all unchanged. Only color, type and
  spacing move.
- No new npm dependency. Fraunces ships through the already-installed `next` package's
  `next/font/google`, the same mechanism already loading Geist Sans/Mono in `src/app/layout.tsx`.
- Scope is exactly: `src/ui/styles.ts`, `src/app/layout.tsx`, `src/app/globals.css`,
  `src/ui/systemColor.ts` (+ its test), and these 19 files: `src/ui/Header.tsx`, `Launcher.tsx`,
  `ConnectAgent.tsx`, `DiffPanel.tsx`, `EventRow.tsx`, `PromptDiffSheet.tsx`, `RecentRuns.tsx`,
  `ReplayScrubber.tsx`, `RunPage.tsx`, `RunView.tsx`, `ScorePanel.tsx`, `Timeline.tsx`,
  `ViolationCard.tsx`, `flow/MetaNodes.tsx`, `flow/EventNode.tsx`, `flow/EventDrawer.tsx`,
  `flow/FlowToolbar.tsx`, `flow/toXyflow.ts`, `flow/FlowView.tsx`. Nothing under `src/ui/worlds/`,
  `src/ui/connect/`, `CompareColumn.tsx`/`CompareRunColumn.tsx`, or any API route — those are the
  explicitly deferred rollout named in the spec.
- After every task: `npm test` (full suite must stay at its current pass count, no regressions),
  `npx tsc --noEmit`, `npx eslint .` — all clean. This plan touches no test-covered logic (no
  jsdom/component tests exist for these files, confirmed against the spec), so "the tests still pass"
  proves "nothing broke," not "the redesign is correct" — Task 6 is where the redesign itself gets
  verified, visually, against a running server.
